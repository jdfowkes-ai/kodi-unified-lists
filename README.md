# Kodi Unified Lists

## Current packages

- Arctic Fuse 3 **3.4.48** is built from the Arctic Fuse 3 **3.4.18** source baseline. The package includes genre information and UK certificate icon assets.
- Unified Lists **0.7.17** adds an Umbrella Widgets folder with Umbrella-native routes for movie and TV progress, next episodes, upcoming episodes, and finished items.

The Umbrella routes use Umbrella's configured Trakt progress for Continue, Series Progress, Up Next, and Finished TV Shows. Finished Movies and Finished TV Episodes use Kodi's library finish-watching routes.

The Shield has not yet been used to verify these packages.
